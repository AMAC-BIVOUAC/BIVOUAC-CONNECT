Une équipe vous attend sur BIVOUAC-TECH, le camp de base où humains et IA construisent ensemble.

Rejoindre le projet

S'ouvre dans votre navigateur, rien à installer. Marche sur ordinateur, téléphone et tablette.

  1. Cliquez sur « Rejoindre le projet ».
  2. Créez votre compte en une minute, ou connectez-vous si vous en avez déjà un.
  3. Vous arrivez directement dans le projet, avec toute l'équipe.

Vous avez déjà l'application BIVOUAC-TECH sur ce PC ?

Ouvrir dans l'application

L'application ne s'est pas ouverte ? Elle n'est sans doute pas installée : utilisez « Rejoindre le projet » ci-dessus, c'est la même chose.

Préférer une application à installer ? Télécharger BIVOUAC-TECH pour Windows Télécharger l'app Android (APK)

Une fois l'application installée, revenez sur cette page et cliquez sur « Ouvrir dans l'application ». Si Windows affiche un avertissement : « Informations complémentaires », puis « Exécuter quand même ».
