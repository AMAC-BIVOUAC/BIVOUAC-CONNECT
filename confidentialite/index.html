Politique de confidentialité

Version bêta privée · mise à jour le 13 novembre 2026

Nous ne demandons pas votre sexe. Nous ne vendons aucune donnée, n'affichons aucune publicité et n'utilisons aucun traceur publicitaire.

Les IA

  • Connecteur (abonnement Claude, ChatGPT…) : quand vous le demandez à votre IA, elle lit les projets dont vous êtes membre et peut y écrire dans l'Atelier IA. Ces échanges passent par le fournisseur de votre IA (Anthropic, OpenAI…), selon votre contrat avec lui. Une IA ne lit jamais vos informations personnelles privées.
  • Clé API (app Windows) : votre clé reste sur votre ordinateur. Les messages que vous adressez à votre IA partent de votre ordinateur vers son fournisseur.
  • Une IA ne peut lire vos messages privés que si vous le lui demandez.

Nos prestataires

  • Supabase (société américaine) : héberge la base de données, les fichiers et la connexion.
  • GitHub (Microsoft) : héberge la version web et les pages publiques comme celle-ci.
  • LanguageTool (Allemagne) : reçoit le texte que vous tapez si le correcteur est activé (désactivable dans Paramètres → Correcteur).
  • Wikimedia Commons : reçoit vos recherches de GIF et de mèmes, seulement quand vous en faites une.
  • Google (serveur STUN) : aide deux ordinateurs à se trouver pour le vocal. Le son et la vidéo passent directement entre les participants, jamais par nos serveurs.

Certains de ces prestataires sont hors de l'Union européenne ; ils s'engagent à protéger les données selon les règles prévues par le RGPD (clauses contractuelles types de la Commission européenne).

Combien de temps ?

  • Tant que votre compte existe. Quand vous le supprimez, tout est effacé tout de suite de la base.
  • Les sauvegardes de sécurité gardent une copie au plus 30 jours, puis elles sont détruites.

Vos droits

  • Voir et télécharger vos données : Paramètres → Mes données → « Télécharger mes données ».
  • Corriger : Paramètres → Mon profil et Mes informations personnelles.
  • Supprimer votre compte : Paramètres → Mes données → « Supprimer mon compte ». Vos projets partagés sont confiés à un autre membre ; ce que vous avez écrit ou envoyé est effacé.
  • Pour toute autre demande (opposition, limitation…), écrivez-nous à l'adresse ci-dessus : réponse sous un mois.
  • Vous pouvez aussi vous adresser à la CNIL.

Sécurité

Connexion chiffrée (HTTPS), règles d'accès vérifiées par la base de données (personne ne voit un projet dont il n'est pas membre), limites contre les abus, sauvegardes régulières. Aucun système n'est parfait : en cas d'incident touchant vos données, nous vous préviendrons.
