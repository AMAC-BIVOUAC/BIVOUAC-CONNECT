# bivouac-connect

Page publique d'autorisation (consentement OAuth) du **connecteur BIVOUAC-TECH**.
Hébergée par GitHub Pages. Elle ne contient aucun secret : seulement l'adresse du projet
Supabase et sa clé *publishable*, faites pour être publiques.

- `oauth/consent.html` : connexion + « Autoriser / Refuser » (appelée par Supabase Auth)
- `index.html` : page d'accueil avec l'adresse du connecteur

Le code de l'application et du connecteur est dans le dépôt privé `AMAC-BIVOUAC/BIVOUAC-TECH`.
